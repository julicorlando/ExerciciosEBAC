# Exercício Cypress - EBAC

Projeto de testes E2E com Cypress para a aplicação:

https://ebac-agenda-contatos-tan.vercel.app/

## Funcionalidades testadas

- inclusão de contato;
- alteração de contato;
- remoção de contato.

Os cenários estão em:

```text
cypress/e2e/agenda-contatos.cy.js
```

## Como executar

```bash
npm install
npm run cypress:open
```

Ou em modo headless:

```bash
npm test
```

## Branch da atividade

```text
exercicio_cypress
```
